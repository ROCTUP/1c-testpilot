# Совместимые сценарии

`tc_run_compatible_scenario` в MCP и `client.run_compatible_scenario()` в Python
запускают сценарии других систем тестирования. Параметр `framework` выбирает
формат сценария. Сейчас поддерживается `tester`.

По умолчанию ответ краткий (`result_mode="summary"`): итог, возвращённое сценарием значение,
счётчики шагов и сведения об ошибках. `result_mode="full"` возвращает также список шагов.
Для набора этот выбор применяется к каждому тесту. При включённом логировании подробности
сохраняются в журнале независимо от режима ответа; пути доступны в поле `logging`.

## Включение

Для публикации инструмента в MCP задайте `TC1C_COMPATIBLE_SCENARIOS=true`.
Python API доступен независимо от этого флага. Исполнители входят в обычную
установку Testpilot.

Для разработчиков: [устройство исполнителей и добавление формата](INTERNALS.md).
