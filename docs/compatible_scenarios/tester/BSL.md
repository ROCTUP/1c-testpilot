# BSL-вызовы в совместимых сценариях Тестера

Этот раздел помогает проверить конкретные выражения в переносимом сценарии
или его библиотеке. Поддержка возможностей Тестера и необходимые изменения
при переносе описаны в [основном руководстве](README.md#ограничения-совместимости).

## Вызовы у объектов сценария

Если готовый сценарий обращается к объекту через точку, например
`Получить("!Товары").УдалитьСтроку()`, проверьте такой вызов по таблице ниже.
Глобальные команды Тестера, например `Выбрать("!Товары")`, описаны
в [основной документации](README.md#поддерживаемое-поведение-тестера).

### Особенности вызовов

`НачатьВыбор()` открывает выбор значения поля. `ВыбратьВариант(Значение)`
выбирает вариант переключателя по тексту или индексу.
`ПерейтиКЗначению(Процент)` устанавливает положение ползунка.
Каждый вызов адресуется сохранённому элементу с проверкой его актуальности.

Для объектов окон добавлены `ПолучитьКомандныйИнтерфейс` / `GetCommandInterface`
и `Закрыть` / `Close`. `ПолучитьОбъект()` / `GetObject()` без аргументов у окна
возвращает его управляемую форму. У командного интерфейса и его групп работают
методы поиска и обхода; у кнопок — `Нажать` / `Click`.
`ГлавноеОкно` / `MainWindow` предоставляет эти обращения к главному окну.
Свойства окна: `Заголовок` / `Caption`, `Главное` / `ЭтоГлавное` / `IsMain`,
`НачальнаяСтраница` / `HomePage`, `URL`.
У кнопки командного интерфейса доступны `ТекстЗаголовка` / `TitleText`, имя и
`НавигационнаяСсылка` / `URL`.

Наличие метода в таблице не делает его применимым к любому элементу: получатель
должен поддерживать эту операцию. Дополнительные ограничения сигнатур:

- `НайтиОбъект`, `НайтиОбъекты`, `ПолучитьОбъект` ищут среди потомков полученного
  объекта. Аргументы: тип, заголовок, имя, таймаут в секундах; все необязательны.
  Тип задаётся через `Тип("ТестируемоеПолеФормы")` и аналогично для формы, таблицы,
  кнопки, группы, декорации. Добавлены типы `ТестируемоеОкноКлиентскогоПриложения`,
  `ТестируемыйКомандныйИнтерфейс`, `ТестируемаяГруппаКомандногоИнтерфейса`,
  `ТестируемаяКнопкаКомандногоИнтерфейса` и английские варианты
  `TestedClientApplicationWindow`, `TestedCommandInterface`,
  `TestedCommandInterfaceGroup`, `TestedCommandInterfaceButton`.
  Заголовок и имя поддерживают `*` и `?`.
  При отсутствии элемента `НайтиОбъект` возвращает `Неопределено`,
  `НайтиОбъекты` — пустой массив, `ПолучитьОбъект` вызывает исключение.
  Нулевой или пропущенный таймаут выполняет один поиск; положительный позволяет
  дождаться появления объекта в пределах общего срока сценария.
- `ПолучитьПодчиненныеОбъекты()` возвращает непосредственных потомков,
  `ПолучитьРодителя()` — родительский объект или `Неопределено`.
  Результаты поиска и обхода доступны как объекты сценария: у них можно читать
  свойства и вызывать поддерживаемые методы. Коллекции возвращаются как массивы
  сценария, а не нативные фиксированные массивы 1С.
- `Приложение` / `App` представляет подключённый клиент и имеет тип
  `ТестируемоеПриложение` / `TestedApplication`. Получение активного окна и обход
  окон возвращают объекты, поиск выполняется по всему приложению.
- `ОжидатьФормированияВыпадающегоСписка(Таймаут)` возвращает булево значение.
  Таймаут — целое число от 0 до 65535 секунд, по умолчанию 60.
- `УдалитьСтроку()` удаляет текущую строку. Возникший вопрос подтверждения
  остаётся для последующих действий сценария.
- `ВвестиТекст` принимает только текст; `ВвестиHTML` — HTML и необязательные
  вложения. Синоним `InputDocumentHTML` не подключён.
- `ПолучитьТекстЯчейки` требует колонку; вариант без аргумента для текущей ячейки
  не реализован. Возвращается текст. Выделенные строки возвращаются как данные
  Testpilot, без создания нативных объектов строк платформы.
- `ВыполнитьВыборИзВыпадающегоСписка` требует переданное значение; вариант без
  аргумента не реализован.
- `ПерейтиКСтроке` принимает условия и необязательное направление; дополнительные
  параметры сверх них не поддерживаются.
- `ВыполнитьКоманду` доступен только через `ГлавноеОкно` / `MainWindow`.
- `Развернуть`, `Свернуть`, `Развернут` работают с текущей строкой либо описанием
  строки из одной пары «колонка — значение». Для `Развернуть` второй аргумент —
  флаг раскрытия подчинённых строк. Составное описание строки пока не поддержано.
- У группы `Развернуть` и `Свернуть` вызываются без аргументов.

Пример поиска колонок и обращения к их родителям:
[`object_search.bsl`](../../../examples/compatible_scenarios/tester/object_search.bsl).

Из свойств элементов формы доступны только `Имя` / `Name`, `ТекстЗаголовка` / `TitleText`,
`Заголовок` / `Caption`, `ИмяФормы` / `FormName`, `Тип` / `Type`.
`Тип` возвращает обозначение типа из Testpilot, а не значение перечисления
`ВидПоляФормы` / `FormFieldType`. Остальные свойства, запись свойств UI-объекта,
само перечисление `FormFieldType` и другие перечисления платформы не подключены.
Исключение — `НаправлениеПереходаКСтроке` / `RowGotoDirection` с `Вниз` / `Down`
и `Вверх` / `Up`.

## Вычисления и значения в сценариях

Поддержан литерал `Null` и тип `Тип("Null")`. Это отдельное значение, отличное
от `Неопределено`: равенство, хранение в коллекциях, параметры и результаты
сохраняют различие. `Строка(Null)` — пустая строка; `"текст" + Null` возвращает
исходную строку. Числовые операции, упорядоченное сравнение и использование
`Null` как булева значения вызывают ошибку. В параметрах и результатах
`Null` передаётся как `{"$type":"null"}`, `Неопределено` — как JSON `null`.

Сценарий исполняется нашим интерпретатором. Полная среда встроенного языка 1С
не создаётся. В частности, пока отсутствуют:

- Директивы `&НаКлиенте`, `&НаСервере` и их варианты; препроцессор `#Если`
  и другие `#`-директивы, кроме `#Область` / `#КонецОбласти` (`#Region` / `#EndRegion`);
  асинхронные процедуры и `Ждать`;
  метки и `Перейти`; подключение/удаление обработчиков событий.
- Ссылки на объекты базы,
  перечисления 1С, UUID,
  `ТаблицаЗначений`, `ДеревоЗначений`, `Запрос`,
  `ТабличныйДокумент`, файловые, сетевые и COM-объекты. Через `Новый` создаются
  `Массив`, `Структура`, `Соответствие`, их фиксированные варианты и
  `СписокЗначений`. Двоичные данные снимка поддержаны
  отдельно: `Снимок()` создаёт значение типа `ДвоичныеДанные` / `BinaryData`,
  методы `Записать` / `Write` и `Размер` / `Size` сохраняют его и возвращают
  размер в байтах. Создание двоичных данных через `Новый` и чтение файлов не добавлены.
- Выполнение строк как кода через `Выполнить` / `Execute`, `Вычислить` / `Eval`,
  косвенные вызовы функций и запуск команд ОС.
- Полная область видимости модуля 1С: локальная функция получает свои аргументы
  и `тут` / `this`, но не произвольные переменные тела вызывающего сценария.
  Присваивание её скалярному параметру не меняет переменную вызывающего кода.
  Объявления функций внутри других функций и экспорт переменных не поддержаны.
- Обход причины и стека ошибки как объектов 1С. Доступны описание и текстовые
  подробности (см. ниже), `ОписаниеОшибки()` и повторный `ВызватьИсключение;`. Ошибки неподдерживаемого
  кода, общий таймаут, ограничения исполнителя и закрытие соединения не скрываются
  блоком `Попытка/Исключение`.

Из стандартных функций доступны **только**:

`Строка` / `String`, `Число` / `Number`, `Цел` / `Int`, `СтрДлина` / `StrLen`,
`СокрЛП` / `TrimAll`, `ВРег` / `Upper`, `НРег` / `Lower`, `Лев` / `Left`,
`Прав` / `Right`, `Сред` / `Mid`, `СтрЗаменить` / `StrReplace`,
`ПустаяСтрока` / `IsBlankString`, `Тип` / `Type`, `ТипЗнч` / `TypeOf`,
`ОписаниеОшибки` / `ErrorDescription`, `Сообщить` / `Message`.

Также `СтрРазделить` / `StrSplit`, `СтрСоединить` / `StrConcat`, `Найти` / `Find`,
`СтрНайти` / `StrFind`, `Символ` / `Char`; сигнатуры приведены ниже.
Дополнительно: `СокрЛ` / `TrimL`, `СокрП` / `TrimR`,
`СтрНачинаетсяС` / `StrStartsWith`, `СтрЗаканчиваетсяНа` / `StrEndsWith`,
`СтрЧислоСтрок` / `StrLineCount`, `СтрПолучитьСтроку` / `StrGetLine`, `КодСимвола` / `CharCode`.
Для значений: `ЗначениеЗаполнено` / `ValueIsFilled`, `Окр` / `Round`,
`Мин` / `Min`, `Макс` / `Max`.

Для дат: `Дата` / `Date`, `ТекущаяДата` / `CurrentDate`, `Год` / `Year`,
`Месяц` / `Month`, `День` / `Day`, `Час` / `Hour`, `Минута` / `Minute`,
`Секунда` / `Second`, `НачалоДня` / `BegOfDay`, `КонецДня` / `EndOfDay`,
`НачалоМесяца` / `BegOfMonth`, `КонецМесяца` / `EndOfMonth`,
`ДобавитьМесяц` / `AddMonth`, `НачалоГода` / `BegOfYear`, `КонецГода` / `EndOfYear`,
`НачалоКвартала` / `BegOfQuarter`, `КонецКвартала` / `EndOfQuarter`,
`НачалоНедели` / `BegOfWeek`, `КонецНедели` / `EndOfWeek`,
`ДеньНедели` / `WeekDay`, `ДеньГода` / `DayOfYear`.
Неделя начинается в понедельник, номер дня недели — 1..7.
Конец периода включает время 23:59:59; конец недели за верхней границей даты
ограничивается 31.12.9999 23:59:59.

`Дата` принимает одну дату, строку `ГГГГММДД[ччммсс]`, три числовых аргумента
«год, месяц, день» либо шесть «год, месяц, день, час, минута, секунда».
Строки вида `25.09.2026` конструктор не принимает. Литералы в одинарных кавычках
содержат 8, 10, 12 или 14 цифр: `'20260925'`, `'2026092512'`,
`'202609251234'`, `'2026-09-25 12:34:56'`; допустимы разделители `.`, `/`, `:`,
`-` и пробелы. Недостающие компоненты времени равны нулю.
Диапазон лет — 1..9999, точность — секунды, часового пояса нет.
Пустая дата — `Дата(1, 1, 1)`.

Поддержаны сравнения дат, прибавление/вычитание секунд справа от даты и
вычитание двух дат с результатом в секундах. `ДобавитьМесяц` сохраняет время
и ограничивает день последним днём полученного месяца. `ТекущаяДата()` использует
местное время компьютера, на котором работает исполнитель сценария.

Также поддержаны `Формат` / `Format` и `НСтр` / `NStr` — см. ниже.
Остальные стандартные функции не реализованы. Не воспроизведено всё приведение типов
платформы: `Строка` принимает строку, число, дату, булево значение или `Неопределено`.
Для даты представление задаёт `TesterDateFormat` (см. [Даты](README.md#даты));
локализованное представление чисел не добавлено. Логические условия требуют
булева значения. `Сообщить(Текст, Статус)` принимает необязательный
`СтатусСообщения` / `MessageStatus`: `БезСтатуса` / `WithoutStatus`,
`Обычное` / `Ordinary`, `Информация` / `Information`, `Внимание` / `Attention`,
`Важное` / `Important`, `ОченьВажное` / `VeryImportant`. По умолчанию — без статуса.
Текст добавляется в `messages`, статус и место вызова — в `message_details` и журнал.
`ВСтудию(Текст)` / `VStudio(Text)` записывает сообщение без статуса.

`Окр(Число, Разрядность=0, Режим=РежимОкругления.Окр15как20)` поддерживает
отрицательную разрядность и режимы `Окр15как10` / `Round15as10`,
`Окр15как20` / `Round15as20` у `РежимОкругления` / `RoundMode`.
В числовом режиме 0 выбирает первый вариант, ненулевое целое — второй.
Например, `Окр(-1.5)` — -2, `Окр(-1.5,0,0)` — -1.
Разрядность по модулю ограничена 1000; чрезмерная точность числа даёт `scenario_limit`.
`Мин` / `Макс` принимают от 1 до 256 значений; сравниваются числа, строки,
булевы значения и даты. Числа и булевы значения допускают совместное сравнение.
`ЗначениеЗаполнено` возвращает ложь для `Неопределено`, `Null`, нуля,
пустой даты, строки из пробелов и пустых коллекций; `Ложь` считается заполненным значением.

### Форматирование и языковые строки

`Формат(Значение, ФорматнаяСтрока)` / `Format` выполняется в исполнителе на Python.
Поддержаны числа, даты, булевы значения; строка возвращается без изменений,
`Неопределено` и `Null` — как пустая строка. Второй аргумент можно пропустить.

```bsl
ТекстСуммы = Формат(1234.5, "ЧДЦ=2;ЧГ=;ЧРД=."); // "1234.50"
ДатаДляИмени = Формат(Дата(2026,9,26), "ДФ=yyyyMMdd"); // "20260926"
АнглийскаяДата = Format(Date(2026,9,26), "L=en_US;DLF=D"); // "9/26/2026"
```

Поддержанные параметры (русское / английское имя):

- Числа: `ЧЦ/ND`, `ЧДЦ/NFD`, `ЧС/NS`, `ЧРД/NDS`, `ЧРГ/NGS`, `ЧН/NZ`,
  `ЧВН/NLZ`, `ЧГ/NG`, `ЧО/NN`, `ЧФ/NF`: количество разрядов, округление,
  десятичный сдвиг, разделители, нулевое значение, ведущие нули, группировка,
  отрицательное представление и шаблон числа.
- Даты: `ДФ/DF`, `ДЛФ/DLF`, `ДП/DE`: явный или локальный формат, пустая дата.
  В явном формате поддержаны русские и английские обозначения дня, месяца,
  года, квартала, часов, минут, секунд, AM/PM, названий месяцев и дней недели.
- Булевы значения: `БЛ/BF`, `БИ/BT`.
- `Л/L`: локаль `ru`/`ru_RU`, `en`/`en_US`, `en_GB`. Другие локали получают
  `unsupported_format_locale`; все региональные варианты платформы не воспроизведены.

Как в 1С, исходный ноль и пустая дата без специального представления дают пустую
строку. `ЧН=` выводит ноль. `ЧЦ` ограничивает число отображаемых разрядов;
`ЧГ=3` отделяет одну группу справа, `ЧГ=3,0` группирует все разряды.
Форматная строка с пробелами внутри значения требует кавычек, например
`"ДФ='dd MMMM yyyy'"`. Неизвестные параметры игнорируются, некорректно составленная
строка использует обычное представление, как в проверенной платформе.
Предел точности и сдвига — 1000, результата — 1 000 000 символов.

Без `Л/L` региональный формат берётся из актуальной Testpilot.epf, а при отсутствии
этих сведений — из локали ОС процесса Testpilot. Числовые разделители выбираются
как при чтении таблиц, включая явно заданный `LatestSeparatorsInfo`.
У булевых значений обычные «Да/Нет» или «Yes/No» определяются языком платформы
из обработки; он может отличаться от языка конфигурации и регионального формата.
`Л/L` и явно заданные `БЛ/BF`, `БИ/BT` имеют приоритет.

`НСтр(Строка, КодЯзыка)` / `NStr` выбирает текст по коду языка:

```bsl
Заголовок = НСтр("ru='Покупатель';en='Customer'", "en"); // "Customer"
```

Явный код имеет приоритет. Если он не задан или пуст, используется `TesterLanguage`,
если эта переменная задана сценарием; затем код языка пользователя из Testpilot.epf;
без обработки — язык локали ОС. Например, `TesterLanguage="en"` задаёт язык для
вложенных вызовов текущего сценария. Язык интерфейса 1С эта переменная не меняет.
При переключении клиента выбирается его язык; значения обработки фиксируются
при её открытии. Поддержан любой явно указанный код, а не только русский/английский.
Коды сравниваются без учёта регистра. Отсутствующий код, некорректная строка или
незакрытые кавычки дают пустую строку; при повторе кода выбирается первый текст.
Точки с запятой внутри кавычек и удвоенные кавычки сохраняются в тексте.

**Отличие от Тестера:** без обработки автоматически используется язык ОС, а не
пользователя базы Тестера. Для точного переноса укажите `TesterLanguage` или второй
аргумент `НСтр`. Подключение обработки для явно заданного языка не требуется.

В описании формы `TesterLanguage` также определяет названия видов полей, групп,
декораций и текст `Hint`. Строка `Type` зависит от отдельной переменной
`TesterScriptVariant`: `"ru"` по умолчанию или `"en"`, если тип не прочитан через
служебную обработку. Это вариант встроенного языка исходной базы Тестера,
а не язык интерфейса. Типы, прочитанные через обработку, имеют язык платформы
клиента. Пример приведён в
[описании формы](README.md#описание-формы-и-её-изменения).

### Информация об ошибке

`Приложение.ПолучитьТекущуюИнформациюОбОшибке()` / `App.GetCurrentErrorInfo()`
возвращает `Неопределено`, если ошибки нет, иначе объект с `Описание` / `Description`.
`ИнформацияОбОшибке()` / `ErrorInfo()` предоставляет ошибку текущего блока
`Исключение`; вне него — `Неопределено`.
`КраткоеПредставлениеОшибки` / `BriefErrorDescription` возвращает описание,
`ПодробноеПредставлениеОшибки` / `DetailedErrorDescription` — описание и подробности:
для ошибки клиента все дополнительные тексты протокола, для ошибки сценария — файл и строку.
Объект поддерживает `ТипЗнч(...)=Тип("ИнформацияОбОшибке")`; свойства причины
и стека как отдельных объектов не предоставляются.

```bsl
Попытка
    Коммандос("e1cib/list/Справочник.Номенклатура");
Исключение
    Сообщить(ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;
Ошибка = Приложение.ПолучитьТекущуюИнформациюОбОшибке();
Если Ошибка <> Неопределено Тогда
    ЗаписатьОшибку(Ошибка.Описание);
КонецЕсли;
```

### Коллекции и типы

Для коллекций также доступен ограниченный набор:

| Тип | Поддержано | Ограничения |
| --- | --- | --- |
| `Массив` / `Array` | Индексы, `Количество` / `Count`, `Добавить` / `Add`, `ВГраница` / `UBound`, `Получить` / `Get`, `Очистить` / `Clear`, `Найти` / `Find`, `Вставить` / `Insert`, `Удалить` / `Delete`, `Установить` / `Set` | Только одномерный конструктор; можно хранить вложенные массивы. До 10 000 элементов. |
| `Структура` / `Structure` | Обращение к свойствам, `Вставить` / `Insert`, `Количество` / `Count`, `Свойство` / `Property`, `Удалить` / `Delete`, `Очистить` / `Clear` | `Свойство(Имя, Значение)` возвращает признак наличия свойства и записывает его значение во второй аргумент. Если свойства нет, второй аргумент получает `Неопределено`. |
| `Соответствие` / `Map` | Индексы, `Вставить` / `Insert`, `Получить` / `Get`, `Количество` / `Count`, `Очистить` / `Clear`, `Удалить` / `Delete` | Ключами могут быть строки, числа, даты, булевы значения и `Неопределено`. Для передачи в UI-действие или наружу ключи должны быть строками. |
| `ФиксированныйМассив` / `FixedArray` | Индексы, `Количество` / `Count`, `ВГраница` / `UBound`, `Получить` / `Get`, `Найти` / `Find`, перебор | Создаётся из обычного массива. `Новый Массив(Фиксированный)` создаёт изменяемую копию. |
| `ФиксированнаяСтруктура` / `FixedStructure` | Свойства, индексы по имени, `Количество` / `Count`, `Свойство` / `Property`, перебор | Создаётся из обычной структуры, по именам свойств и значениям либо без аргументов. `Новый Структура(Фиксированная)` создаёт изменяемую копию. |
| `ФиксированноеСоответствие` / `FixedMap` | Индексы, `Получить` / `Get`, `Количество` / `Count`, перебор | Создаётся из обычного соответствия. `Новый Соответствие(Фиксированное)` создаёт изменяемую копию. Ограничения ключей совпадают с `Соответствие`. |
| `СписокЗначений` / `ValueList` | Индексы, `Количество` / `Count`, `Добавить` / `Add`, `Вставить` / `Insert`, `Получить` / `Get`, `Удалить` / `Delete`, `Очистить` / `Clear`, `НайтиПоЗначению` / `FindByValue`, `Индекс` / `IndexOf`, `Скопировать` / `Copy`, `ЗагрузитьЗначения` / `LoadValues`, `ВыгрузитьЗначения` / `UnloadValues`, `ЗаполнитьПометки` / `FillChecks`, перебор | Конструктор без аргументов; до 10 000 элементов. `ЗагрузитьЗначения` принимает обычный массив и заменяет содержимое списка. |
| `ЭлементСпискаЗначений` / `ValueListItem` | Чтение и изменение `Значение` / `Value`, `Представление` / `Presentation`, `Пометка` / `Check` | Возвращается из списка; отдельного конструктора нет. Представление — строка, пометка — булево значение. |

Фиксированные коллекции сохраняют состав на момент создания. Изменять его нельзя,
но вложенные изменяемые объекты остаются доступны: например, можно добавить строку
во вложенный массив. Копирование не создаёт копий вложенных значений. Для сравнения
фиксированных коллекций и поиска коллекции среди значений учитывается сам объект,
а не совпадение его содержимого.

Пример списка значений:

```bsl
Варианты = Новый СписокЗначений;
Элемент = Варианты.Добавить("Опт", "Оптовая продажа", Истина);
Варианты.Добавить("Розница", "Розничная продажа");
Заявить(Варианты).Содержит("Опт").Вмещает(2);
Найденный = Варианты.НайтиПоЗначению("Опт");
Найденный.Пометка = Ложь;
Варианты.Удалить(Найденный);
```

`Скопировать()` создаёт новые элементы списка с прежними значениями, представлениями
и пометками. `НайтиПоЗначению()` возвращает первый найденный элемент или `Неопределено`;
`Индекс()` — индекс элемента либо `-1`, если его нет в этом списке.
В результате сценария список превращается в массив объектов с полями
`value`, `presentation`, `check`; фиксированные коллекции — в обычные массивы
или объекты результата. При сохранении окружений их BSL-типы сохраняются.

Дополнительно поддержаны:

| Вызов | Поведение |
| --- | --- |
| `СортироватьПоЗначению` / `SortByValue`, `СортироватьПоПредставлению` / `SortByPresentation` | Необязательное направление: `НаправлениеСортировки.Возр` / `SortDirection.Asc` (по умолчанию) или `Убыв` / `Desc`. Явное `Неопределено` также означает возрастание. Равные ключи сохраняют порядок. По представлению сравнивается именно поле `Представление`, включая пустую строку. |
| `Сдвинуть` / `Move` | `(ЭлементИлиИндекс, Смещение)`. Перемещает существующий элемент; выход за границы даёт ошибку. |
| `НайтиПоИдентификатору` / `FindByID` | Возвращает элемент по его числовому идентификатору либо `Неопределено`. |
| `Элемент.ПолучитьИдентификатор` / `Item.GetID` | Возвращает идентификатор элемента внутри списка. |

Идентификаторы начинаются с нуля и сохраняются при сортировке и перемещении.
Удаление и очистка не сбрасывают счётчик. `Скопировать()` создаёт новый список
с идентификаторами с нуля. Хранение окружений сохраняет идентификаторы и следующий
номер; старые записи списков без идентификаторов также читаются.

По значению поддержаны `Неопределено`, `Null`, булевы значения, числа, строки,
даты и поддержанные коллекции. Разные типы упорядочиваются по проверенному порядку
1С; коллекции одного типа сохраняют взаимный порядок без сравнения содержимого.
Другие объекты, например элементы UI, как ключи сортировки не поддержаны.
Для строк используется системная ICU с различением диакритики и без различения
регистра. На Linux нужна библиотека `libicu`; при её отсутствии возвращается
`collation_unavailable`. Настройки локали процесса не меняются. Порядок необычных
символов может зависеть от версии ICU.

У списка значений пока не поддержаны картинки и диалоги выбора/отметки.
`Тип` / `ТипЗнч` принимают русские и английские имена новых типов,
включая `НаправлениеСортировки` / `SortDirection`.

Второй аргумент `Свойство` можно записать в ранее объявленную переменную,
существующее свойство структуры или элемент массива/соответствия:

```bsl
Покупатель = Неопределено;
Если _.Свойство("Покупатель", Покупатель) Тогда
    Установить("Покупатель", Покупатель);
КонецЕсли;
```

`Тип` / `ТипЗнч` поддерживают только строку, число, дату, булево значение,
`Неопределено`, перечисленные коллекции и элемент списка значений, сам тип и объекты тестируемой формы, поля,
таблицы, кнопки, группы и декорации, окна и командного интерфейса. Для снимков
добавлен тип двоичных данных. Также поддержаны `Null`, `ИнформацияОбОшибке`,
`СтатусСообщения` и `РежимОкругления`. Другие типы платформы в эту модель не входят.

Между вложенными сценариями можно передавать объекты интерфейса, но во внешнем
результате разрешены только строки, числа, даты, булевы значения, `Неопределено`
и коллекции таких значений; двоичные данные снимка возвращаются объектом
`{"$type":"binary","base64":"..."}`. Дата передаётся в параметрах и возвращается
как `{"$type":"date","value":"2026-09-25T12:34:56"}`. При запуске сценария из
Python через `client.run_compatible_scenario()` в аргументе `parameters` также
можно передать объект Python `datetime` без часового пояса и микросекунд.
Внутри BSL-сценария он становится значением типа `Дата` —
см. [примеры передачи даты](README.md#даты).
Представления ссылок и других типов
из инструментов выполнения кода остаются обычными структурами.

### Строковые функции

| Функция | Аргументы и результат |
| --- | --- |
| `СокрЛ` / `TrimL`, `СокрП` / `TrimR` | Убирают пробельные символы соответственно слева и справа. |
| `СтрНачинаетсяС` / `StrStartsWith`, `СтрЗаканчиваетсяНа` / `StrEndsWith` | `(Строка, Подстрока)`. Сравнение с учётом регистра; пустая подстрока вызывает ошибку. |
| `СтрЧислоСтрок` / `StrLineCount` | Разделители LF, CRLF и CR. Завершающий перевод строки не добавляет ещё одну строку; у пустого текста одна строка. |
| `СтрПолучитьСтроку` / `StrGetLine` | `(Текст, Номер)`. Нумерация с 1, за пределами — пустая строка. |
| `КодСимвола` / `CharCode` | `(Строка, Позиция=1)`. Код UTF-16; вне строки возвращает -1. |
| `СтрРазделить` / `StrSplit` | `(Строка, Разделители, ВключатьПустые=Истина)`. Каждый символ второго аргумента — отдельный разделитель. Возвращает массив. Пустые части сохраняются по умолчанию; явное `Неопределено` в третьем аргументе исключает их. |
| `СтрСоединить` / `StrConcat` | `(Массив, Разделитель="")`. Соединяет представления элементов. Принимает значения, для которых поддержана `Строка`; даты используют `TesterDateFormat`. |
| `Найти` / `Find` | `(Строка, Подстрока)`. Позиция первого вхождения с единицы; при отсутствии — 0, для пустой подстроки — 1. Регистр учитывается. |
| `СтрНайти` / `StrFind` | `(Строка, Подстрока, Направление, НачальнаяПозиция, НомерВхождения)`. Последние три аргумента необязательны: поиск с начала, с края строки по направлению, первого вхождения. Вхождения считаются без перекрытия. |
| `Символ` / `Char` | `(Код)`. Создаёт один символ UTF-16. Числовой аргумент усекается до целого; воспроизведено преобразование платформы к 32-битному коду. Если полученный код больше 65535, возвращается пустая строка. |

Для поиска доступны `НаправлениеПоиска.СНачала` / `SearchDirection.FromBegin`
и `НаправлениеПоиска.СКонца` / `SearchDirection.FromEnd`.
`СтрНайти("abcabc", "abc", , , 2)` возвращает 4.
Пропуск аргумента направления и явное `Неопределено` различаются: последнее
не является допустимым направлением. Позиции поиска считаются в единицах UTF-16,
как в платформе: `Найти("😀X", "X")` возвращает 3.

Из `Символы` / `Chars` доступны `ПС` / `LF`, `ВК` / `CR`, `Таб` / `Tab`.
Свойства этих констант и направлений поиска доступны только для чтения.
Результат разделения ограничен 10 000 элементами, соединения — 1 000 000 символов.
Полное региональное преобразование произвольных объектов к строке не реализовано;
используются представления поддержанных типов исполнителя.

### Изменение коллекций

- `Массив.Найти(Значение)` возвращает индекс с нуля или `Неопределено`.
  Учитываются тип и регистр: `Истина`, `1` и `"1"` различаются. Вложенная
  коллекция находится по тому же объекту, а не по совпадению её содержимого.
- `Массив.Вставить(Индекс, Значение)` сдвигает следующие элементы. При индексе
  за концом массива промежуток заполняется `Неопределено`; значение можно опустить.
- `Массив.Установить(Индекс, Значение)` заменяет существующий элемент,
  `Массив.Удалить(Индекс)` удаляет его со сдвигом следующих элементов.
  Индекс вне массива вызывает ошибку. В этих трёх методах числовой индекс
  усекается до целого, как в платформе.
- `Структура.Удалить(Имя)` не учитывает регистр и допускает отсутствие свойства;
  `Структура.Очистить()` удаляет все свойства.
